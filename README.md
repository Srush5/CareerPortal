# CareerPortal - Modern Job Application Platform

CareerPortal is a modern, responsive single-page job board application built with React. It allows users to explore career opportunities, search and filter job listings, view detailed descriptions, bookmark favorite positions and submit job applications with robust validation.

## Features
* Hero Search & Filtering: Quick job discovery via keyword searching and category filtering.
* Dynamic Job Data: Expanded listings featuring diverse tech roles, salaries and remote types.
* Interactive Application Form: Multi-field tracking including experience, CTC expectations and custom file upload styling.
* Responsive Design & Dark Mode: Fully adaptive UI layout supporting both light and dark viewing themes.


## Built With
* React.js (Component-based architecture)
* React Router (Client-side routing and navigation)
* CSS3 / Inline Styles (Custom modern styling workflows)
